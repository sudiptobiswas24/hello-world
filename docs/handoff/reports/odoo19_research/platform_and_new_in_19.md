# Odoo 19 platform features, what is new in 19 over 18, and this ERP's platform

_Reading guide._ Source links are of five kinds. `docs19 …` = the Odoo documentation, branch 19.0, local copy (commit 2472f7d), `content/applications/…`; `src19 …` = the Odoo 19.0 Community source tree, manifests only (638 modules; the tree holds no models or views); `docs18/18.0 …` = the same documentation repository at `origin/18.0`, or the 18.0 Community manifest on GitHub (used only to test whether a module existed in 18); `erp …` = this repository, read-only; `web …` = third-party pages, flagged as weak. **Edition rule used throughout:** the documentation almost never states the edition (it says so on a handful of pages: WhatsApp, UrbanPiper, Data Recycle, Peppol), so "Community" means the module is present in the 19.0 Community manifest tree, and "Enterprise (inferred)" means no such module is in that tree. Where a diff measure is quoted it is lines in `.rst` files only (images ignored). "New in 19" means: absent from 18.0 docs or manifests, or stated as such by a 19.0 page; "Reworked" means the page was substantially rewritten but the feature existed in 18.

## 1. What does Odoo 19 offer on each cross-cutting platform feature, which parts are new in 19, and is each Community or Enterprise?

### Takeaway
Odoo 19's genuinely new platform items are: an AI layer (Ask AI, agents, AI fields, AI server actions, AI document sorting, voice transcription; Enterprise by inference), the JSON-2 external API with `/doc` pages (the old XML-RPC/JSON-RPC are deprecated for removal), session/inactivity timeouts and portal passkeys, an offline read-only mode, IoT drivers moving into Community, and rewrites of Sign, Spreadsheet/Dashboards, Documents, Studio automation and user-portal documentation. The rest of the platform (chatter, activities, mail gateway, portal, access groups, import/export, TOTP, base_import, automation rules, Razorpay) existed in 18 and changed little; WhatsApp is explicitly Enterprise-only and essentially unchanged.

## 3. For each platform feature, does this ERP have it, where, and how relevant is it to a woven polypropylene sack plant in India?

### Takeaway
The ERP is stronger than Odoo on controlled posting, role separation, immutability, race-safe writes and plant-specific floor and statutory tools, and weaker on communication and reach: it has no external-party portal, no WhatsApp or inbound email, no 2FA or session timeouts, no API keys or webhooks, no pivot/graph/Excel analysis layer, and no user-built automation. Before go-live the relevant platform items are already built (roles, history, attachments, SMTP, CSV import and export, GST payloads); the items to schedule soon after are API tokens, session timeout and 2FA, WhatsApp/email reach, a pivot or Excel layer, and record-level scoping beyond sales reps.
